# Security policy

## Supported versions

Only the latest release (the hosted deployment and the `main` branch) gets
security fixes.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem.

- Preferred: GitHub private vulnerability reporting, on this repository's
  **Security** tab → **Report a vulnerability**
  (https://github.com/robertobarbedo/sitecoreai-marketplace-content-transfer-api-console/security/advisories/new).
- Or email rb205@proton.me with "SECURITY" in the subject.

Include what you found, how to reproduce it, and the impact you expect.

## What happens next

| Step | Target |
| --- | --- |
| Acknowledge the report | 3 business days |
| Triage and severity rating (CVSS) | 7 days |
| Fix critical vulnerabilities | 7 days |
| Fix high vulnerabilities | 30 days |
| Fix medium and low vulnerabilities | Next release |

We coordinate disclosure with you and credit you unless you'd rather stay
anonymous. We ask for up to 90 days before public disclosure.

Confirmed incidents that affect customers are reported to Sitecore and to
affected customers within 72 hours, and zero-day vulnerabilities within 24
hours, as the Sitecore Marketplace requires.

## Scope

This repository's code and the hosted deployment of this app. Issues in
SitecoreAI itself go to Sitecore (https://www.sitecore.com/trust).
